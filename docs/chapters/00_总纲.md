## 一之一、⭐⭐ 完整产品链路（2026-11-07 收尾）

**论文第 08 章的骨架，按数据流顺序：**

```
config.py        定参数（k / n_decoy / n_pick / sep_digits / seed）
        ↓
vectorform.py    造题（11 节点 + 50 干扰值 + 50 选项 + 60 工具，GPU 批量）
        ↓
module.py        拆成中间态（V### 变量 / E### 函数 / C## 系数 / N## 选项
                 + 每个函数的四维特征）
        ↓
skins.py         抽象（74 条精确描述 × 10 套语法模板 × 变量名词替换）
        ↓
toolconsole.py   交给模型（60 个计算器，两级界面，全量行为记录）
        ↓
⏳ 题面           未做 —— 由「中间态 + 控制台」共同诞生（Frank 定：最后一步）
```

**⭐ 抽象层的核心区分（Frank 2026-11-07 定，论文里必须写清）：**

| 部件 | 能不能乱换 | 原因 |
|---|---|---|
| **变量** | ✅ **随便换名词** | 只是「值的指代」，本身无意义 |
| **函数** | ❌ **必须符合特征** | 换了特征，模型判断不出它干什么 |

**⚠️ 两条措辞铁律：**
```
① 名词后带「的值」—— 让 LLM 知道那是一个数，不是一件物体
② 不能只说「粒子专家」，要说「计算粒子运动什么内容的专家」
```

**⭐⭐ 工具的呈现哲学（Frank 2026-11-07，论文 05 章 §5.4.7）：**

> 「工具可以说自己是工具，可以说自己是擅长某方面的专家，
> 可以说自己是懂什么计算的热心人，这都符合 AGI 在通用场景下的定义。
> 总之需要过滤信息，经过运筹计算，判断最优效率的路线和备选路线。」

**⭐ 这一条把「句式多样性」从文字游戏提升为**被测能力**：**
**真实通用场景里，人面对的信息就是杂乱的（有的专业、有的随意、有的信息不全），
模型要能从中筛出有用信息并判断最优路径。**

**→ 身份可换，「干什么」必须一致。13 套语法分四组口吻。**

> 如数学计算和语言处理等能力，结合新需求做出的结合，并非是唯一解，

## 二、核心论点链（贯穿全文的主线）

```
① 通用性要求覆盖未枚举场景               ← 定义
        ↓
② 场景不可穷举 → 不能依赖人预置的场景提示   ← 推论
        ↓
③ 因此必须自主认知并使用工具              ← 判据根
        ↓
④ 测法：给行为特征，不给语义说明           ← 协议
        ↓
⑤ 指标：提示依赖度、工具识别步数、步骤效率   ← 测量
```

**⚠️ 这条链是全篇骨架，任何一章都要能指回它。**

## 三、⭐ 四维度同源的推导（2026-11-05 新增，详见 `04_准入条件.md` §4.3）

**⚠️ 这一条推翻了原先「迁移是唯一直接由三通推出的一条」的说法。**

```
                    通用性
                      │
        覆盖现实世界的复杂性
                      │
        现实任务本身就是复合的、长链的
                      │
        ┌─────────┬─────────┬─────────┐
        ↓         ↓         ↓         ↓
    长链复合    多模态    不预置路径   通道完整
        │         │         │         │
     ┌──┴──┐      │         │         │
     ↓     ↓      ↓         ↓         ↓
   维持  不可信  多模态     绕路     （四维度见 4.4）
```

**Frank 2026-11-05：「长链复杂本身就是通用衍生出来的」**

**⭐ 因此四条都源于通用性，只是路径不同：**
- **迁移** ← 场景不同，但底层方法相同
- **长链** ← 现实复合，故任务复合
- **多模态** ← 现实输入天然多模态
- **绕路** ← 不预置路径，故通道有缺口就会被绕

**「四维度」是一个根源的四条分支，不是「一条真、三条补」。**

## 四、术语约定（全篇统一）

| 术语 | 定义 | 首次出现 |
|---|---|---|
| **准 AGI** | AGI 的准备期与全能智能底座 | 01 |
| **三通** | 场景通用 / 人群通用 / 规范通用 | 03 |
| **准入条件（admission condition）** | 不满足则不能称为准 AGI，但可照常测试与出报告 | 04 |
| **复合探针（composite probe）** | 串联多道关卡的测试题形式 | 05 |
| **难度轴 L** | 计算复杂度 L1–L4 | 05 |
| **提示轴 P** | 工具提示强度 P1–P5 | 05 |
| **语言轴 G** | 语言覆盖（中/英 → 联合国六种正式语文） | 05 |
| **提示依赖度** | P1 得分 − P5 得分 | 06 |
| **预指派（pre-assignment）** | 先定答案、再倒推题目。学术界正式术语（Horiyama et al. 2023） | 08 |
| **区分度 δ** | `δ_opt = 10^(−sep_digits)`；`δ_final = δ_opt × √k` | 05/08 |
| **增殖/协作** | ⚠️ 本文不测，见 09 局限 | 09 |

**⚠️ 难度是三维不是两维（2026-11-07 更正）：**
**L（计算复杂度）× P（提示强度）× G（语言覆盖），三者互相独立，可任意组合（例如 L1P3G2）。**
